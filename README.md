# 윷놀이 🎲

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 윷놀이. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- 윷 네 개를 던져 평평한 면(배)의 개수로 정한다: 1개 도(1칸) · 2개 개(2칸) · 3개 걸(3칸) · 4개 윷(4칸) · 0개 모(5칸). 윷 한 개가 평평하게 나올 확률은 0.55
- **윷·모가 나오거나 상대 말을 잡으면 한 번 더** 던진다. 던진 결과는 쌓아 두었다가 원하는 말에 하나씩 쓴다 (결과 칩을 눌러 고름)
- 판은 바깥 길 20칸 + 지름길. 모서리(5번·10번)에 멈췄다가 다음에 움직이면 지름길로 질러간다. **가운데에 멈췄다가 움직이면 출발점 쪽(우하단)으로** 가고, 지름길을 타고 가운데를 지나가는 중이면 곧장 이어진다
- 상대 말이 있는 칸에 멈추면 그 칸의 말을 **모두 잡아** 대기로 돌려보낸다. 내 말이 있는 칸에 멈추면 **업어서** 함께 움직인다 (한꺼번에 완주도 된다)
- 출발점을 지나치면 완주. 내 말 4개를 먼저 모두 완주시키면 이긴다. 백도(뒤로 한 칸)는 넣지 않았다
- 컴퓨터 쉬움은 잡을 수 있으면 잡고 나머지는 거의 아무거나, 어려움은 잡기·완주·업기·지름길과 상대에게 잡힐 위험을 따진다. 어려움이 쉬움을 이기는 비율은 시험으로 확인한다
- 컴퓨터를 이긴 횟수는 `yutWins` (로비 표시용), 온라인 전적은 `yutOnline`
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(대국 중 끊겨도 30초 안에 돌아오면 이어서) · 던지거나 옮길 때마다 30초(넘기면 시간패) · 기권 · 한 판 더(먼저 하는 쪽이 바뀜). 윷은 서버가 던지고 서버가 같은 규칙(`public/logic.js`)으로 모든 수를 검사하므로, 차례가 아니거나 규칙에 어긋난 입력은 무시한다. 방 코드를 짧은 시간에 많이 틀리면 잠깐 막는다
- PC: Space/Enter 던지기, M 소리. 말이나 점선 칸을 눌러 옮긴다

규칙과 컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리·온라인 연결은 `public/game.js`, 방·매칭은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(규칙·컴퓨터), `test/server.test.js`(서버를 띄워 두 손님이 한 판을 끝까지 두는 흐름·입력 검사·재접속 등).
